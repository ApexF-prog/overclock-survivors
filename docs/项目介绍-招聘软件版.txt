【版本 A · 完整版（497 字，适合“项目经历/项目描述”框）】

《超频幸存者》是纯前端无尽生存射击游戏，个人独立开发，公网可玩。技术栈：原生 HTML5 Canvas + JavaScript + Web Audio，零框架零依赖，双击即可运行。

1. 自研分层引擎：17 个模块解耦状态机／渲染／战斗／强化／音频／UI，按序加载；核心循环固定 1/60 步长，判定在各帧率下一致可复现。
2. 性能优化：同屏 200+ 敌人用对象池、空间哈希碰撞、屏外剔除、粒子上限与伤害数字聚合；配帧率档位（自动/60~144）、动态分辨率与泛光快速路径，密集场景稳 60 帧，高刷跑满 120。
3. 玩法：无尽层制、三选一随机强化、6 大羁绊（2/4/6 三档）、永久成长研究所、每日挑战（日期哈希确定性同题 + 独立日榜）、超武进化图鉴。
4. 音频：Web Audio 实时合成 5 首背景乐及变奏、40 种音效，经压缩器与增益补偿构成响度链路，支持三档响度与三路音量调节。
5. 质量：64 项冒烟测试（VM mock + 固定种子）与 5 个 Edge headless/CDP 真浏览器验证脚本，覆盖玩法、性能、UI 回归，线上零 JS 异常。

试玩：https://apexf-prog.github.io/overclock-survivors/
